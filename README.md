# 把自由写进路上 · 滚动互动网页

用浏览器打开运行中的本地预览：http://127.0.0.1:4173/ 。网站文件在 `dist/` 中，部署时上传该目录即可。

首屏从背景开始，标题逐字渐显，风筝随后摆动；两侧文案沿山势进入，黄色道路由远到近展开，完成后文案上浮。首页完整展现一次后，向上返回仍保持展开；刷新页面重新播放入场。其余滚动控制的动画向下推进、向上还原；人物带有走路及马尾摆动效果。

两组卡片缓慢循环移动，支持触摸左右滑动、鼠标拖动和键盘左右键。目的地随机抽取三张签图之一，先显示吊牌，约 0.65 秒后弹出分享面板。奖品随机显示手账本、抱枕、大疆相机或杯垫，使用 PSD 原始透明素材，放在白色圆角方框内。行李箱后面的黄色衬底已移除。

“子话题”和“活动奖励”木牌随滚动渐显；“子话题”木牌完整出现后，小人再从木牌后方移出并渐显。地图的步骤标题、内容与绿色箭头按阅读顺序依次渐显。行李箱里的四件奖品分别缓慢上下浮动。

整页默认以每秒 35 像素向下移动，手动操作时暂停，停止约 0.9 秒后从当前位置继续；弹窗打开时暂停，到底部停止。速度和恢复时间可在 `dist/motion-settings.js` 修改。页面没有慢移开关和右上角演示说明按钮。

抽奖与积分为浏览器本地演示。第三方直接分享、真实发布与奖品发放尚未接入平台接口。

开启系统“减少动态效果”时，页面显示完整静态版。

原始 PSD 保持不变。线上站点目前尚未发布。

## GitHub Pages 部署

将本文件、`dist/` 和 `.github/` 一起上传到 GitHub 仓库根目录，推送到 `main` 分支。在仓库 Settings → Pages → Build and deployment 中，将 Source 设为 GitHub Actions。运行完成后，Actions 中的部署结果会显示访问链接。

已提供 `.github/workflows/pages.yml`，自动发布 `dist/`，无需安装依赖或构建。若默认分支不是 `main`，修改工作流中的分支名。静态资源均使用相对路径，支持仓库子路径访问。

操作参考：[GitHub Pages 自定义工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
